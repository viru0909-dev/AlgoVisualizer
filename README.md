# AlgoVisualizer

Welcome to **AlgoVisualizer**! 🚀

An interactive, sleek, and highly educational pathfinding visualization tool. This application brings classic pathfinding algorithms to life on a dynamic 2D grid and includes a powerful **Code Execution Tracker** to let you step through algorithmic logic line-by-line synced perfectly with visual animations!

## Features

- **Dynamic Visualization**: Watch algorithms search for targets in real-time.
- **Code Execution Tracker**: A 70/30 split-screen IDE panel seamlessly maps grid animations to their core JavaScript execution lines.
- **Modern UI/UX**: Premium dropdowns, glassmorphism info cards, and a VS Code-themed code panel toggle.
- **Interactive Information**: Hover context cards detailing description, **Time Complexity**, and **Space Complexity** for each unique algorithm.

## Supported Algorithms
- **Dijkstra's Algorithm** (weighted): guarantees the shortest path
- **A* Search** (weighted): arguably the best pathfinding algorithm; uses heuristics
- **Greedy Best-first Search** (weighted): a faster, more heuristic-heavy version of A*
- **Swarm Algorithm** (weighted): a mixture of Dijkstra's Algorithm and A*
- **Convergent Swarm Algorithm** (weighted)
- **Bidirectional Swarm Algorithm** (weighted)
- **Breadth-first Search** (unweighted): great fundamental algorithm
- **Depth-first Search** (unweighted): very bad for pathfinding

## Local Setup
1. Clone the repository.
2. Run `npm install` to grab all dependencies.
3. Start the application via `npm start`.
4. Open the visualizer locally on your browser.

Enjoy exploring the depths of Algorithms, one node at a time!
