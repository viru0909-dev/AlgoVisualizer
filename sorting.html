How to Use Sorting Visualizer
Watch and understand how sorting algorithms work step by step with live bar animations.
Getting Started
1
Pick a Sorting Algorithm from the dropdown — start with Bubble Sort if you're new, or try Quick Sort / Merge Sort for advanced patterns.
2
Adjust Size slider to control how many bars are generated — fewer bars = easier to follow, more bars = a better big-picture view.
3
Set the Speed slider — drag left to slow down and watch every comparison, right to see the full sort in seconds.
4
Click Visualize! to start the animation. Click New Array to generate a fresh random set of bars.
Reading the Bars
5
Blue = Default   Yellow = Comparing   Red = Swapping
6
Purple = Pivot   Orange = Min/Selected   Green = Sorted
Code Tracker
7
Click Code Tracker in the top-right of the navbar to open a split-screen IDE showing the algorithm's code with the current line highlighted.
8
Change the language (JS / Python / Java / C++) in the code panel header to see the algorithm in your preferred language.
Tip: Hover over an algorithm name in the dropdown for a quick summary card showing its time and space complexity before you run it!
